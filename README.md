# Card de Perfil Interativo

Atividade de React feita com **Vite**.

## 📌 O que foi feito
- Criação do componente **ProfileCard** que recebe `name`, `age` e `isStudent` como props.
- Exibe nome, idade e se a pessoa é estudante ou não.
- Botão que mostra um **alert** com o nome da pessoa.
- Estilização separada em `ProfileCard.css`.

## 🚀 Como rodar
1. Clonar o repositório:
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   cd seu-repositorio
   ```
2. Instalar dependências:
   ```bash
   npm install
   ```
3. Rodar o projeto:
   ```bash
   npm run dev
   ```
4. Abrir no navegador:
   ```
   http://localhost:5173
   ```
